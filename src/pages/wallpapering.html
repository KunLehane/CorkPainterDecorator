How we prep

Flat walls first

Paper shows every bump underneath it, so the wall has to be right before a drop goes up. Before hanging we:

  • Strip old paper and wash off the old paste
  • Fill and sand cracks, holes and old fixing marks
  • Size the wall so the paste grips evenly
  • Hang lining paper where the wall needs it
  • Mark a plumb line so the first drop is straight
  • Plan the pattern so the repeat lands well at eye level
